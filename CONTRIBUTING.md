# Contributing to PICLas

Thank you for your interest in contributing!
PICLas is an open-source project and very happy to accept contributions from the community.
This project welcomes contributions of all kinds - bug reports, feature requests, code improvements, documentation updates, and more.
All contributions are coordinated through issues and direct communication with the PICLas team.

## How to Collaborate

To ensure your contributions can be integrated smoothly, please follow these guidelines:
1. Ensure you have a GitHub account.
2. Check existing issues before opening a new one.
3. [Open an issue](https://github.com/piclas-framework/piclas/issues) and clearly describing the issue:
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Environment information (OS, version, etc.)
   - Minimal example if possible
4. Discuss your proposed change with the PICLas team in the issue.

## File Header
New source files must start with the standard license header, see the [Style Guide](https://piclas.readthedocs.io/en/latest/developerguide/styleguide.html#file-header).

## Code of Conduct
Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) to ensure a welcoming environment for everyone.
